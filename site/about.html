Who built this

Ali Rasheed

Developer. Built ToonSaz because the tools that existed assumed you wrote in English, paid monthly, and were happy uploading your face to someone else's server.

Why this exists

I kept running into the same wall. A creator writes a script in Roman Urdu, wants a cartoon presenter to say it, and the options are: a subscription tool that renders in the cloud and charges per minute, an English-only pipeline that turns “assalamualaikum” into mush, or a research repository with forty dependencies and no interface.

So the goal was narrow on purpose. One machine, no account, a real Urdu and Hindi path, and an export you can publish. Not a platform. Not a studio. A tool that finishes one job.

What that changed

Three decisions came directly out of that goal:

  • Everything runs locally. The server binds to localhost and refuses anything else. Your recording never leaves the folder it sits in.
  • No key, no gate. Gesture planning is a rule engine, not a model call. It works with the network unplugged. The optional AI path is optional in the literal sense.
  • Devanagari is a first-class feature. Most tools treat non-Latin scripts as an edge case. Here the converter sits in the script panel, where the words are.

What I actually wrote

The parts that took the longest were not the visible ones. A deterministic gesture planner that never repeats a pose twice in a row. A rig that swaps wardrobe without breaking the jaw. A transliteration layer that keeps Devanagari matras and Urdu diacritics instead of silently dropping them. Cross-file drift tests so a new avatar cannot be half-registered.

The character art is mine, drawn with AI assistance and cleaned into vector rigs. The render pipeline is built on HyperFrames, GSAP, Rhubarb and Faster-Whisper — all credited in the repository.

Honest limits

There is no macOS or Linux installer. There is no custom character upload. The built-in voice needs a connection because Edge TTS is Microsoft's endpoint, not a local model. If those are dealbreakers, the FAQ says so plainly rather than burying it.
