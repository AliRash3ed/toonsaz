Changelog

Only the changes a creator would notice, plus the bugs that were embarrassing enough to write down.

Unreleased

Settings, offline voices, and a real setup step

  • API keys in the editor. A Settings panel writes OpenRouter and Hugging Face credentials to the local avatar/.env.local and activates the feature immediately. Keys are never sent back to the page.
  • Windows offline voices. A fourth voice source uses the speech voices already installed with Windows. No key, no network, no model download.
  • One-command setup. npm run setup installs the npm packages, checks Node, Python and ffmpeg, and pre-fetches the pinned HyperFrames renderer that export uses.
  • Export documented. The quick start, download page and docs now explain the HyperFrames step and the first-run browser download instead of leaving it as a surprise.
  • 128 tests. Added offline-voice request, catalog and pipeline coverage.
13 Nov 2026

1.0.0 — the Urdu and Hindi release

  • Devanagari converter. Roman Urdu, Hinglish and Urdu script now convert to Devanagari in the script panel, with a preview you can reject. Hindi voices finally pronounce the script instead of guessing at Latin letters.
  • Gesture aliases for Urdu and Devanagari. The keyword rules were Roman-only, so a script written in اردو fell back to generic rotation. Urdu script went from 4 segments to 8 on the same paragraph, Hindi from 5 to 7.
  • The Arabic question mark now counts. ؟ (U+061F) was ignored by an ASCII-only check, so every Urdu question missed its thinking cue.
  • Combining marks survive tokenising. Devanagari matras and Urdu diacritics were being stripped, turning नमस्ते into नमसत before any rule saw it.
  • 23 new characters. The Forma2D set joins the original rigs: 49 registered, 40 shown in the editor, 36 curated for batch jobs.
  • 125 tests at the 1.0 cut. Added multilingual gesture regressions, transliteration tests and cross-file registration guards so an avatar cannot be half-wired.
  • Renamed to ToonSaz. Same tool, a name people can spell.
2 Oct 2026

0.9 — split layout and alpha export

  • 9:16 split puts footage above the avatar; 16:9 split puts it beside.
  • Transparent background plus WebM export with an alpha channel.
  • Custom background upload, normalised to PNG, JPEG or WebP.
  • Placement controls: X, Y and scale, with a reset.
18 Sep 2026

0.8 — the cue track

  • Editable gesture and expression lanes under the stage. Manual cues override the planner until the next rebuild.
  • Forced variety: no two adjacent segments may share both a pose and an expression.
  • Silent rehearsal mode — preview gestures with no generated speech.
  • Timed transcript import from SRT, VTT, Whisper JSON or plain segments.
29 Aug 2026

0.7 — first working pipeline

  • Rhubarb lip sync from a real recording, driven by Faster-Whisper word timings.
  • Edge TTS script-to-voice with the live Microsoft voice catalogue.
  • Forty-pose rig with a jaw, eyes, brows and two arms.
  • Local server on port 3010 with a host check and origin guard.
