Documentation · v1.0

Build your first video

The editor is one page with three numbered sections. Read this once and you will not need it again.

Before the first run

First run npm run setup once in the avatar folder. It installs the npm packages, checks Node, Python and ffmpeg, and pre-fetches the HyperFrames renderer. Then start the server with npm run library, or double-click Start_Avatar_Studio.bat. The editor opens at http://127.0.0.1:3010/library.html. Nothing is served to your network — the server rejects any request whose host is not localhost.

01 · Choose your presenter

The cast strip holds forty characters. Clicking one swaps the rig on the stage immediately, without rebuilding anything. Below the stage, the Gesture, Emotion, Look and Scene tabs change how that presenter appears and behaves.

  • Gesture — leave it on “Follow script cues” and the planner decides, or pin one pose for the whole clip.
  • Emotion — same idea, for the face. A pinned expression overrides automatic emotions but never touches the audio.
  • Look — outfit, glasses, headwear, earrings, neckwear. Not every rig supports every item; the menu only lists what fits.
  • Scene — aspect ratio, background, placement and the split-layout video.

Every change is saved to assets/avatar-settings.js the moment you make it. There is no Save button because there is nothing to forget.

02 · Voice and footage

Upload a recording

Drop in a WAV, MP3, M4A, AAC, OGG, FLAC, OPUS, AIFF, WebM or WMA file. With “transcribe automatically” ticked, the server runs Faster-Whisper, then Rhubarb, then the cue planner, in that order. This is the highest-quality path because the mouth follows a real human performance.

Edge TTS

Type your script and let Microsoft's neural voices read it. Pick a locale, pick a voice, set the maximum internal pause, and press generate. This path needs an internet connection and no API key.

Which voice for which script? A Hindi voice (hi-IN) reads Devanagari. An Urdu voice (ur-PK) reads Urdu script. If your script is in Roman Urdu, convert it first — see below.

Windows offline

Use a voice already installed in Windows Speech. Pick it from the list, set the speed, and press generate. Nothing leaves the machine and no model is downloaded. The list depends on the Windows language packs installed; English ships with Windows, and other languages appear after you add their speech pack in Windows Settings.

Which voice for which script? A Windows voice speaks the language of its language pack. For Urdu, Hindi or Arabic, install that Windows speech pack first, or use Edge TTS with a matching voice.

OmniVoice clone

Upload three to sixty seconds of clean speech you own or have permission to use, type the exact words spoken in that clip, and tick the consent box. Cloning is English and Spanish only, and needs a Hugging Face token. Add it with Settings in the editor header.

Optional services

Two extras are off until you add a key: AI cue analysis through OpenRouter, and voice cloning through Hugging Face. Press Settings in the editor header — the panel saves the key to avatar/.env.local on this machine and switches the feature on immediately, with no restart. Remove saved key switches it off again. The page never receives the stored key back; it only shows whether the service is ready.

03 · The spoken words

The script box must match the narration word for word. It is what the gesture planner reads, so a script that disagrees with the audio produces cues that land in the wrong place.

Converting to Devanagari

Press Convert to Devanagari under the script box. The converter detects the writing system and shows a preview without touching your text.

  • Roman Urdu and Hinglish convert by rule, with a dictionary for words where spelling is ambiguous.
  • Urdu script converts through a letter table plus a dictionary, because Urdu leaves short vowels unwritten.
  • English prose is recognised and left alone rather than mangled.
  • Brand names and acronyms like OpenRouter or VoxCPM2 stay in Latin script; AI and SEO are spelled out.

Read the preview before pressing Use this script. If a word is wrong, edit the textarea afterwards. Applying the conversion clears the timed transcript, because those timings belonged to the old words.

Timed transcripts

If you already have word timings — SRT, VTT, Whisper JSON or plain segment JSON — paste them under “Have timestamps?”. The planner uses them instead of estimating, which tightens every cue.

The cue track

Under the build buttons, two lanes show hands and expression across the timeline. Click a block to inspect the phrase that produced it. If the planner guessed wrong, edit the row and press save — your manual cues win until the next rebuild.

Automatic planning follows three rules: a semantic keyword sets the pose when one matches, gaps are filled on a five-second cadence, and no two adjacent segments may share both a gesture and an expression. That last rule is why the performance never freezes.

Export

Name the file, pick a format, press export.

  • MP4 — H.264, 1080p, 30 fps. The one to upload.
  • WebM — VP9 with an alpha channel. Only meaningful with the transparent background, and the one to composite in an editor.

Renders land in avatar/renders/. A download link appears in the header when the file is ready.

Export is the only step that needs HyperFrames. The editor calls a pinned HyperFrames CLI to rasterise the composition and ffmpeg to encode it. npm install does not provide that CLI — npm run setup pre-fetches it, and the first export downloads a headless Chrome build (about 150 MB). After that, exports are local. If it reports “Local npx could not be found”, Node is not on PATH for the shell that started the server.

Command line

Everything the editor does is also a script, which is what you want for batches:

cd avatar
npm run avatar-job -- --avatars
npm run avatar-job -- --script my-script.txt --avatar forma-zara --aspect 9:16

--avatars lists the curated ids. The job runner reads the same settings file as the editor, so a batch run and a manual run produce the same video.

Checks

Two commands keep the project honest:

npm run test    # 125 unit and integration tests
npm run check   # HyperFrames lint, runtime, layout, motion, contrast

When something looks wrong

  • The mouth does not move. The narration has no word timings. Rebuild and watch for the transcription step.
  • Gestures repeat. The script is too short for the cadence. Add phrases or pin a gesture you like.
  • The avatar is cropped. Check placement under Scene — scale above 100% pushes the rig outside the frame.
  • Devanagari looks off. Transliteration is a draft. Fix the word in the textarea; the next build reads your corrected text.
