Why a source download first? A self-contained installer has to bundle a Python runtime, ffmpeg and a headless browser — roughly 1.2 GB — and each of those has its own licence. Shipping it half-tested would waste your afternoon. The source route runs the exact same code.

Set it up in two commands

Unzip the download, open a terminal in the folder, and run:

cd avatar
npm run setup
npm run library

npm run setup installs the npm packages, checks Node, Python and ffmpeg, and pre-fetches the HyperFrames renderer. If something is missing it prints the command that fixes it instead of failing silently.

Then open http://127.0.0.1:3010/library.html. On Windows you can skip the terminal entirely: double-click Start_Avatar_Studio.bat in the project root. It starts the server, waits for it, and opens the editor for you.

Exporting

Export is the step that needs HyperFrames. The editor calls a pinned HyperFrames CLI to rasterise the composition, then ffmpeg encodes it. The first export downloads the CLI and a headless Chrome build (about 150 MB), so give it a few minutes; later exports run locally.

Pick MP4 or WebM in the header, name the file, and press Export video. The render lands in avatar/renders/ and a download link appears in the header. Transparent WebM needs the transparent background, the avatar-only layout, and imported video switched off.

If something does not start

  • Port 3010 is busy. An older server is still running. Close the window it was started from, or end the node process, then relaunch.
  • “Edge TTS dependencies are unavailable.” Run python -m pip install edge-tts and restart the server. Rendering still works; only generated speech is blocked.
  • “Local npx could not be found.” Node is not on PATH for the shell that started the server. Reinstall Node with the PATH option and relaunch.
  • No voices in the Edge tab. The catalogue is fetched live. Check your connection and reload.
  • Rhubarb is missing. The lipsync tool lives in tools/rhubarb. Re-download the repository if that folder is empty.
  • Renders are silent. Whisper needs to finish before the build starts. Watch the status line above the stage.

Optional credentials

You do not need any of these. Open the editor and press Settings in the header to add a key; it is written to avatar/.env.local on your machine and activates immediately. You can also copy avatar/.env.example to avatar/.env.local by hand and fill in only what you use:

  • OPENROUTER_API_KEY — lets the cue planner ask a model for gesture suggestions. The local rule engine is the fallback and needs nothing.
  • OMNIVOICE_HF_TOKEN — enables OmniVoice reference-voice cloning. English and Spanish only.
  • AVATAR_WHISPER_MODEL — override the Whisper model size if the default is too slow or too small for your machine.
