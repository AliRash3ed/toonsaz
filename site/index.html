Three passes, one pipeline

It reads the words, then it performs them.

Every job runs the same deterministic path. Nothing is guessed at render time, so the same script and the same audio always produce the same video.

01

Voice

Record yourself, import an audio file, type a script for Edge TTS, or use the installed Windows voices completely offline. Urdu, Hindi, English, Spanish and every other voice in the catalogue.

02

Sync

Faster-Whisper times every word. Rhubarb turns the audio into mouth shapes. The jaw and lips follow the actual waveform, not a timer.

03

Perform

A rule engine reads the transcript and picks a gesture and an expression per phrase, capped at five seconds so nothing holds too long.

What you actually get

Small tool, complete job.

Cast

40 characters

Hand-drawn vector rigs with swappable outfits, glasses, headwear, earrings and neckwear. Three body styles, from flat illustration to clay.

Performance

17 gestures, 7 expressions

Point up, count on fingers, sweep, pinch, hold a hand to the chest. Poses are rigged, not swapped images, so they move.

Language

Devanagari converter

Paste Roman Urdu, Hinglish or Urdu script and get Devanagari a Hindi voice can actually pronounce. Proofread it, then build.

Layout

Split screen

Put footage above the avatar in 9:16, or beside it in 16:9. Import an MP4, WebM, MOV, MKV, M4V or AVI and it is normalised for you.

Output

MP4 or alpha WebM

1080p at 30 fps. Export an opaque MP4 for publishing, or a WebM with a transparent background for editing on top of your own footage.

Privacy

Your files stay put

The server binds to 127.0.0.1 and refuses foreign origins. Uploads, transcripts and renders never leave the machine.

Built for Urdu and Hindi creators

The part most tools skip.

Hindi voices only read Devanagari. If you write “assalamualaikum dosto” or “السلام علیکم دوستو”, a Hindi voice mangles it. ToonSaz converts either one before it speaks.

A preview you can reject.

Transliteration is a draft, not a verdict. The converter shows its work next to your text and waits. If a word is wrong, you fix it before anything is rendered — and the timed transcript is cleared so gesture timing is recalculated instead of silently going stale.

  • Roman Urdu, Hinglish and Hindi transliteration
  • Urdu script with aspiration and nasal marks handled
  • English prose is detected and left alone
  • Brand names and acronyms stay readable

Straight answers

What it does not do.

A tool is easier to trust when it tells you where the edges are.

  • It does not animate photographs of real people. These are illustrated characters, not deepfakes.
  • It does not build a custom character from your drawing yet. You get the forty that ship with it.
  • Edge TTS needs internet. It is Microsoft's endpoint, not an offline model — use the Windows offline voices or import your own audio for a fully offline run.
  • There is no macOS or Linux installer. The scripts are portable, but only Windows is packaged.
  • There is no cloud render, no team workspace and no timeline editor. One presenter, one script, one export.
  • Urdu script to Devanagari leans on a dictionary. Uncommon words may need a proofread.

Questions people actually ask

Before you download.

Is ToonSaz free?

Yes. Free and open source, no account, no subscription, no credit card. You download it, run it on your own computer, and keep every video you make.

Do I need an API key?

No. Rendering, lip sync, gestures, expressions and export all work without one. Two optional features can use a key: OpenRouter for AI gesture analysis, and a Hugging Face token for OmniVoice cloning. Both stay off unless you add credentials yourself.

Does it work offline?

Mostly. Rendering, lip sync, gesture planning and export run entirely offline. Edge TTS needs a connection because it uses Microsoft's speech endpoint. Use the Windows offline voices or import your own recording and the whole job runs offline.

Which languages can it speak?

Any language with an Edge TTS voice — Urdu, Hindi, English, Spanish, Arabic, Bengali, French, German, Japanese, Korean, Portuguese, Russian, Italian and more. The Devanagari converter covers Roman Urdu, Hinglish and Urdu script.

What do I need installed?

Windows 10 or 11, Node.js 20 or newer, Python 3.11 or newer, and ffmpeg on your PATH. Run npm run setup once in the avatar folder — it installs the npm packages, verifies the tools, and fetches the pinned HyperFrames renderer that export uses. The launcher starts the server and opens the editor.

Does it upload my video or my voice?

No. Files stay on your machine, and the server only listens on 127.0.0.1. The only outbound requests are the ones you trigger: speech synthesis, an optional cue request, or an optional voice clone call.

Can I publish the videos commercially?

The ToonSaz source is MIT licensed and the character art ships with the project, so you can publish what you make. Check the licences of the tools it calls — edge-tts is GPL-3.0 and ffmpeg builds differ — before you redistribute those binaries yourself.

How long does a render take?

A one-minute 1080p clip typically renders in well under a minute on a normal laptop. The slow part is the first run, when Whisper downloads its model.
