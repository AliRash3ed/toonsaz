Privacy

The short version: this website has no analytics, and the app does its work on your computer. Below is the long version, because “we respect your privacy” is not a policy.

This website

toonsaz.vercel.app is a set of static HTML files. It sets no cookies, loads no fonts or scripts from third parties, and contains no analytics, pixels or session recorders. There is nothing to consent to because there is nothing collecting.

The site is hosted on Vercel. Like any web host, Vercel keeps standard request logs — IP address, user agent, requested path, timestamp — for security and abuse prevention. Those logs are Vercel's, governed by Vercel's privacy policy, and I do not receive or query them.

The application

ToonSaz runs as a local server on 127.0.0.1:3010 and opens in your browser. It refuses requests whose host header is not localhost and rejects cross-origin writes, so other machines on your network cannot reach it and other websites cannot drive it.

Your uploads, transcripts, settings and rendered videos stay in the project folder on your disk. There is no sync, no backup service and no telemetry. Uninstalling means deleting the folder.

What leaves your computer

Only what you explicitly trigger. There are three outbound paths:

  • Edge TTS. When you generate speech, the script text is sent to Microsoft's Edge read-aloud endpoint through the edge-tts package. Microsoft receives the text and your IP address. If you never use the Edge TTS tab, nothing is sent.
  • OpenRouter. Only if you add an OpenRouter key in Settings and tick “Use OpenRouter semantic cue analysis”. The request contains the transcript text and word timings. It never contains audio, video or images.
  • OmniVoice. Only if you add a Hugging Face token in Settings and submit a reference clip. That clip and its transcript are sent to the Hugging Face Space that performs the clone.

Windows offline voices add no outbound path. The script is spoken by a voice installed on your PC, and the generated audio stays in the local project folder.

There is no fourth path. Model downloads for Whisper and the headless browser are fetched from their public sources during setup and then cached locally.

Voice cloning and consent

Cloning is off by default and requires a credential you supply. The editor requires you to tick a box confirming you own the voice or have explicit permission to use it. Do not clone a voice you do not have rights to. If someone reports a clone made with this tool, the honest answer is that the tool asked and the operator lied — but the request is still to stop.

Children

The app is not directed at children under 13 and collects no personal information from anyone, so there is nothing special to say here beyond that.

Your rights

There is no account and no stored profile, so there is no personal data to access, correct, export or delete on my side. If you believe something of yours is hosted here, write to me and I will remove it.

Changes

If this policy changes, the date at the top changes and the diff appears in the changelog. There is no mailing list to notify, which is itself a privacy feature.
